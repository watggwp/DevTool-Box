⌁ Serial Monitor ดูและส่งข้อมูลพอร์ตอนุกรม (Arduino / ESP32) ผ่าน Web Serial API เปิดเครื่องมือ → 64 Base64 เข้ารหัส / ถอดรหัส Base64 รองรับ UTF-8, URL-safe และไฟล์ เปิดเครื่องมือ → % URL Encode percent-encoding และแยก query parameters เปิดเครื่องมือ → 0x Hex / Text แปลงข้อความเป็น hex bytes และ hex dump เปิดเครื่องมือ → {} JSON จัดรูปแบบ ย่อ ตรวจสอบ และ escape JSON เปิดเครื่องมือ → JWT JWT Decoder ถอด header / payload ของ JSON Web Token เปิดเครื่องมือ → # Hash / CRC MD5, SHA, CRC32, CRC16 Modbus, XOR / SUM checksum เปิดเครื่องมือ → ⏱ Timestamp Unix epoch ↔ วันที่เวลา (local / UTC) เปิดเครื่องมือ → 2/16 Number Base แปลงเลขฐาน 2 / 8 / 10 / 16 พร้อม bit และ signed เปิดเครื่องมือ → ID UUID / Random สร้าง UUID v4, random bytes และ password เปิดเครื่องมือ →
