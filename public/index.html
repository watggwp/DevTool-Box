รวมเครื่องมือสำหรับนักพัฒนาและงาน embedded แต่ละเครื่องมือแยกเป็นหน้าของตัวเอง ทำงานในเบราว์เซอร์ทั้งหมด ไม่ส่งข้อมูลขึ้นเซิร์ฟเวอร์

⌁ Serial Monitor ดูและส่งข้อมูลพอร์ตอนุกรม (Arduino / ESP32) ผ่าน Web Serial API 64 Base64 เข้ารหัส / ถอดรหัส Base64 รองรับ UTF-8, URL-safe และไฟล์ % URL Encode percent-encoding และแยก query parameters 0x Hex / Text แปลงข้อความเป็น hex bytes และ hex dump {} JSON จัดรูปแบบ ย่อ ตรวจสอบ และ escape JSON JWT JWT Decoder ถอด header / payload ของ JSON Web Token # Hash / CRC MD5, SHA, CRC32, CRC16 Modbus, XOR / SUM checksum ⏱ Timestamp Unix epoch ↔ วันที่เวลา (local / UTC) 2/16 Number Base แปลงเลขฐาน 2 / 8 / 10 / 16 พร้อม bit และ signed ID UUID / Random สร้าง UUID v4 และ random bytes
