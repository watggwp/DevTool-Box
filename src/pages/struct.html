Struct Parser

แยกค่าจาก hex bytes ตามรูปแบบที่กำหนด เหมาะกับการอ่าน packet จากเซนเซอร์ struct ของ C/C++ หรือข้อมูลดิบจาก Serial

วิธีเขียนรูปแบบ

เขียนชนิดข้อมูลเรียงตามลำดับไบต์ คั่นด้วยช่องว่าง จุลภาค หรือขึ้นบรรทัดใหม่ ใส่ชื่อนำหน้าด้วย ชื่อ: ได้ และใช้ # เขียนหมายเหตุท้ายบรรทัด

u8 i8จำนวนเต็ม 1 ไบต์ ไม่มี / มีเครื่องหมาย
u16 i16จำนวนเต็ม 2 ไบต์
u32 i32จำนวนเต็ม 4 ไบต์
u64 i64จำนวนเต็ม 8 ไบต์
f32 f64float และ double (IEEE 754)
bool1 ไบต์ ค่าไม่ใช่ 0 = true
strNข้อความ N ไบต์ เช่น str8 (ตัด 0x00 ท้ายออก)
hexNแสดงไบต์ดิบ N ไบต์
skipN / padNข้าม N ไบต์ เช่น padding ของ struct
le / beต่อท้ายเพื่อกำหนด endian เฉพาะตัว เช่น u16be
[N]array N ตัว เช่น adc:u16[4]
