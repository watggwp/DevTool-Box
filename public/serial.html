Serial Monitor Web Serial API

เชื่อมต่อบอร์ด Arduino / ESP32 / STM32 ผ่าน USB ได้โดยตรงจากเบราว์เซอร์ รองรับ Chrome, Edge, Opera บน Windows / macOS / Linux / Android (ไม่รองรับ Firefox และ Safari)

เบราว์เซอร์นี้ไม่รองรับ Web Serial API กรุณาใช้ Google Chrome หรือ Microsoft Edge และเปิดผ่าน HTTPS หรือ localhost
ไม่พบพอร์ตหรือยกเลิกการเลือก ถ้าเสียบบอร์ดแล้วแต่ไม่เห็นพอร์ต COM ในรายการ ให้ตรวจสอบ driver ของชิป USB-to-Serial ตามแผง "ไม่เห็นพอร์ต?" ด้านล่าง

          ไม่เห็นพอร์ต COM หรือเชื่อมต่อไม่ได้? (driver และวิธีแก้)
          

            
เบราว์เซอร์ไม่สามารถตรวจสอบหรือติดตั้ง driver ให้ได้ ถ้า Windows ไม่รู้จักชิป USB-to-Serial บนบอร์ด พอร์ตจะไม่ปรากฏในหน้าต่างเลือกพอร์ตเลย ให้ทำตามนี้

            
    
              
  1. เปิด Device Manager (กด Win+X แล้วเลือก Device Manager) ดูหมวด Ports (COM & LPT) ถ้ามีเครื่องหมายตกใจสีเหลือง หรืออุปกรณ์ไปอยู่ใน "Other devices" แสดงว่ายังไม่มี driver
    2. 
              
  2. ดูว่าบอร์ดใช้ชิปอะไร (พิมพ์อยู่บนตัวชิปใกล้พอร์ต USB) แล้วดาวน์โหลด driver จากผู้ผลิตโดยตรงด้านล่าง
    3. 
              
  3. ติดตั้ง driver แล้วถอด/เสียบสาย USB ใหม่ จากนั้นกด "เชื่อมต่อ" อีกครั้ง
    4. 
              
  4. ถ้ายังไม่เห็น ลองเปลี่ยนสาย USB (สายบางเส้นเป็นสายชาร์จอย่างเดียว ไม่มีสายข้อมูล) และปิดโปรแกรมอื่นที่เปิดพอร์ตค้างอยู่ เช่น Arduino IDE Serial Monitor, PuTTY
    5. 
            

            

              CP210x (Silicon Labs)ESP32 DevKit, NodeMCU บางรุ่น
              CH340 / CH341 (WCH)Arduino clone, NodeMCU, ESP32 ราคาประหยัด
              CH343 / CH9102 (WCH)ESP32-S3 / C3 DevKit รุ่นใหม่
              FTDI FT232 (VCP)FTDI cable, Arduino Nano รุ่นแท้
            

            
บอร์ดที่ใช้ USB native เช่น Arduino Leonardo, Pico, ESP32-S3 (USB CDC), STM32 (CDC) ปกติไม่ต้องลง driver บน Windows 10/11

            
ข้อความ "Failed to open serial port" มักเกิดจากพอร์ตถูกโปรแกรมอื่นใช้อยู่ หรือ baud rate ที่ driver ไม่รองรับ
