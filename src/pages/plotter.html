Serial Plotter Web Serial API

วาดกราฟเรียลไทม์จากค่าที่บอร์ดส่งผ่าน Serial แบบเดียวกับ Arduino Serial Plotter ใช้ได้กับ Chrome, Edge, Opera กดปุ่ม "ลองด้วยข้อมูลตัวอย่าง" เพื่อดูการทำงานโดยไม่ต้องต่อบอร์ด

เบราว์เซอร์นี้ไม่รองรับ Web Serial API กรุณาใช้ Google Chrome หรือ Microsoft Edge (ยังลองโหมดข้อมูลตัวอย่างได้)
ยังไม่ได้เชื่อมต่อ
บรรทัดล่าสุด: - 0 จุด
รูปแบบข้อมูลที่รองรับ (ตัวอย่างโค้ด Arduino)

ส่งค่าหนึ่งชุดต่อหนึ่งบรรทัด คั่นด้วยช่องว่าง แท็บ หรือจุลภาค ใส่ชื่อเส้นกราฟได้ด้วย ชื่อ:ค่า รองรับสูงสุด 8 เส้น

void loop() {
  float t = readTemp();
  float h = readHumidity();
  Serial.print("temp:"); Serial.print(t);
  Serial.print(",hum:"); Serial.println(h);
  delay(50);
}

ตัวอย่างบรรทัดที่ใช้ได้: 1.2 3.4 5, temp:25.3,hum:60, a=1 b=2 ถ้าส่งบรรทัดที่เป็นชื่ออย่างเดียว เช่น temp hum จะใช้เป็นชื่อเส้นของค่าที่ไม่มีชื่อ
