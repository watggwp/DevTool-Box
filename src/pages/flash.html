Firmware Flasher ESP32 / ESP8266 / UF2

อัปโหลดไฟล์ .bin ลงบอร์ด ESP32, ESP32-S2/S3/C3/C6/H2 และ ESP8266 ผ่าน USB จากเบราว์เซอร์โดยตรง ไม่ต้องติดตั้ง Python หรือ esptool ใช้ได้บน Chrome / Edge

เบราว์เซอร์นี้ไม่รองรับ Web Serial API กรุณาใช้ Google Chrome หรือ Microsoft Edge บนคอมพิวเตอร์ และเปิดผ่าน HTTPS หรือ localhost
1เชื่อมต่อบอร์ด 2เลือกไฟล์ .bin 3อัปโหลด

1. เชื่อมต่อบอร์ด ESP

ยังไม่ได้เชื่อมต่อ

ถ้าเชื่อมต่อไม่ได้ ให้กดปุ่ม BOOT ค้างไว้ แล้วกด EN / RST หนึ่งครั้ง ปล่อย BOOT แล้วกดเชื่อมต่อใหม่

2. ไฟล์เฟิร์มแวร์และตำแหน่ง (address)

หาไฟล์ .bin ได้จากไหน และควรใส่ address อะไร
  • Arduino IDE: เมนู Sketch แล้วเลือก Export Compiled Binary ไฟล์จะอยู่ในโฟลเดอร์ build ของ sketch ไฟล์ที่ลงท้าย .merged.bin ใช้ address 0x0 ได้เลย
  • PlatformIO: ไฟล์อยู่ที่ .pio/build/<env>/firmware.bin ใช้ address 0x10000 ส่วน bootloader.bin และ partitions.bin อยู่โฟลเดอร์เดียวกัน
  • ESP-IDF: ดูคำสั่ง idf.py flash ที่พิมพ์ออกมา จะบอก address ของแต่ละไฟล์
  • Bootloader: ESP32 และ ESP32-S2 อยู่ที่ 0x1000 ส่วน S3, C3, C6, H2 และ ESP8266 อยู่ที่ 0x0 หน้านี้จะตั้งค่าให้อัตโนมัติหลังเชื่อมต่อ
